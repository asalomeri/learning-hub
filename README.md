# Learning Hub | مركز التعلّم

فهرس عربي تفاعلي لدروس قصيرة في أساسيات البرمجة. يتضمن النموذج الأولي أمثلة تعليمية في Python وHTML، مع بحث نصي وفلاتر حسب اللغة والمستوى.

## المزايا الحالية

- ستة دروس تمهيدية مع شرح وهدف تعلّمي ومثال برمجي.
- بحث مباشر في عنوان الدرس وموضوعه وشرحه ومحتواه.
- فلاتر للغة البرمجة والمستوى، مع زر لمسح الفلاتر.
- واجهة عربية من اليمين إلى اليسار وتعمل على الشاشات الصغيرة.
- لا يحتاج المشروع إلى حزم أو خادم خلفي.

## التشغيل محليًا

انسخ المستودع وافتح `index.html` في متصفح حديث:

```bash
git clone https://github.com/asalomeri/learning-hub.git
cd learning-hub
```

يمكنك أيضًا تشغيل خادم ملفات ثابتة اختياريًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تجربة البحث

ابحث مثلًا عن `الحلقات` أو `Python`، ثم جرّب تحديد اللغة أو المستوى. البحث يتجاهل التشكيل وبعض اختلافات الألف العربية الشائعة.

## النشر

بعد الدمج إلى `main`، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر. بعدها يعمل سير GitHub Actions تلقائيًا مع كل تحديث إلى `main`، ويمكن تشغيله يدويًا من تبويب Actions. بعد نجاح أول نشر، سيكون الرابط:

https://asalomeri.github.io/learning-hub/

## إضافة درس

أضف عنصرًا إلى مصفوفة `lessons` في `script.js`. لكل درس عنوان ولغة ومستوى وموضوع وشرح وهدف ومثال برمجي وكلمات مفتاحية. تُعرض النصوص باستخدام `textContent` لتبقى البيانات نصًا عاديًا.

## الحالة والاتجاه القادم

هذا نموذج أولي بمحتوى مضمّن داخل التطبيق، وليس محرك بحث ذكيًا أو منصة دورات كاملة. يمكن تطويره لاحقًا بإضافة مصادر دروس موثوقة، وروابط للمحتوى الأصلي، وتصنيفات أكثر بعد مراجعة المحتوى.
