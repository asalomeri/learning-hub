# Learning Hub | مركز التعلّم

فكرة مشروع لمساعدة المتعلمين على الوصول إلى دروس البرمجة باللغة العربية من خلال فهرس تفاعلي وبحث.

## حالة المشروع

المستودع حاليًا يحتوي على هذا الوصف فقط؛ لم يُضف التطبيق أو الدروس بعد. لذلك لا تتوفر نسخة تجريبية أو صور للواجهة، ولا يمكن تشغيل البحث حاليًا.

## ما الذي يهدف المشروع إلى تقديمه؟

- فهرس منظم لدروس البرمجة العربية.
- طريقة للبحث عن الدروس والوصول إليها بسهولة.
- واجهة تساعد المتعلم على استكشاف المحتوى.

هذه أهداف مقترحة وليست ميزات متاحة بعد.

## الحصول على المستودع

يمكنك تنزيل الملفات الحالية للاطلاع عليها:

```bash
git clone https://github.com/asalomeri/learning-hub.git
cd learning-hub
```

لا توجد حاليًا أوامر تثبيت أو تشغيل. ستُضاف التعليمات ورابط التجربة والصور هنا عندما يصبح التطبيق جاهزًا.

## المساهمة

يمكنك اقتراح فكرة أو مناقشة طريقة تنظيم الدروس والبحث عبر تبويب **Issues**. يُرجى عدم إضافة بيانات شخصية أو مفاتيح سرية إلى المستودع.
