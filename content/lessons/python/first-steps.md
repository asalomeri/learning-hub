# أهلًا بك في Python

تُستخدم Python في مجالات كثيرة، وتمتاز بسهولة قراءة صياغتها. لنبدأ بإنشاء متغير وطباعة قيمته:

```python
name = "ليلى"
print(f"مرحبًا يا {name}")
```

## المتغيرات

المتغير اسم يشير إلى قيمة. يمكنك إسناد نص أو رقم إليه:

```python
lessons_count = 3
language = "Python"
```

جرّب تغيير القيم وتشغيل البرنامج لترى النتيجة.
